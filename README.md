# My website

I have created a website, kind of like a portfolio, to present myself. <br>
I am using SvelteKit to create the interactive pages and tailwindCSS and SkeletonLabs to style them. 
<br>
The website is now deployed [here](https://kinglee-website.vercel.app/)! It is now fitted for mobile screens as well.

## Usage

To use this as a template you `git clone https://github.com/jesjoha/my-website.git` and then `cd my-website`.
When you are in the root of the project you run ```npm install```, which will install the necessary dependencies to run the project.
With the dependencies installed you can run the development server with `npm run dev`.
